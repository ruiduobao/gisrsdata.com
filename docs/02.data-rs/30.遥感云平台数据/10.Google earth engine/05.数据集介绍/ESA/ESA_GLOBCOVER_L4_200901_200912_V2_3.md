# GlobCover：全球土地覆盖图（2009）

英文原名：GlobCover: Global Land Cover Map

## 这是什么数据

GlobCover 2009 是一幅全球土地覆盖图，基于 ENVISAT 的中分辨率成像光谱仪（MERIS）以全分辨率模式获取的 1B 级数据，空间分辨率约为 300 米。

## 覆盖范围与时间

- 覆盖范围：全球
- 时间范围：2009-01-01 至 2010-01-01

## 分辨率与规格

- 空间分辨率：约 300 米
- 数据类型：影像（Image），在 Google Earth Engine 中调用

| 波段 | 说明 | 分辨率（米） | 波长 |
| --- | --- | --- | --- |
| landcover | 该土地覆盖图由对 2009 年全球 MERIS FR 镶嵌影像时间序列的自动、区域调谐分类导出。全球土地覆盖图共有 22 个土地覆盖类别，采用联合国（UN）土地覆盖分类系统（LCCS）定义 | 300 |  |
| qa | 二值质量波段，指示是否使用了参考数据集而非 GlobCover 分类方案的输出 | 300 |  |

## 能拿来做什么

- 全球土地覆盖本底（2009 年）
- 土地覆盖变化对比的基准图
- 全球环境建模的输入数据

## 怎么获取

在 Earth Engine 中调用：

```js
var dataset = ee.Image('ESA/GLOBCOVER_L4_200901_200912_V2_3');
```

- 数据集编号（Earth Engine ID）：`ESA/GLOBCOVER_L4_200901_200912_V2_3`
- 提供方：ESA、Google Earth Engine
- 官方介绍：https://developers.google.com/earth-engine/datasets/catalog/ESA_GLOBCOVER_L4_200901_200912_V2_3
