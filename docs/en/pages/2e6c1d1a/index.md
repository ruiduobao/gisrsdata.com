# Global Seasonal Sentinel-1 Interferometric Coherence and Backscatter V2019 Coherence

Original name: Global Seasonal Sentinel-1 Interferometric Coherence and Backscatter V2019 Coherence

## What this dataset is

This data set is the first-of-its-kind spatial representation of
multi-seasonal, global C-band Synthetic Aperture Radar (SAR)
interferometric repeat-pass coherence and backscatter signatures.
Coverage comprises land masses and ice sheets from 82 degrees
Northern to 79 degrees Southern latitudes. The data set is derived
from multi-temporal repeat-pass interferometric processing of about
205,000 Sentinel-1 C-band SAR images acquired in Interferometric
Wide-Swath Mode from 1-Dec-2019 to 30-Nov-2020.

Coherence is a measure of the similarity, or correlation, between two
complex SAR images acquired over the same area at different times, ranging
from 0 (no correlation/high noise) to 1 (perfect correlation). The dataset
was generated by analyzing every possible image pair up to 48 days apart.
It reports the median coherence for specific, standardized temporal
baselines (repeat intervals) aggregated over each season.

The scale factor has already been applied to each of the bands. If you
would like to do calculations using the digital numbers from the original
rasters, load
*Earth_Big_Data/GLOBAL_SEASONAL_S1/V2019/COHERENCE_RAW* instead.

## What you can use it for

- Surface stability and change detection via coherence loss
- Seasonal decorrelation analysis of vegetation and snow
- Coherence prior assessment for InSAR applications

In Earth Engine:

```js
var dataset = ee.ImageCollection('Earth_Big_Data/GLOBAL_SEASONAL_S1/V2019/COHERENCE');
```
